# AI MV Studio v1 Roadmap

## Phase 1：保留與穩定

- 保留原有歌曲生成介面
- 維持 GitHub Pages 可直接運行
- 保留 localStorage 專案儲存
- 建立 v1 JSON schema
- 建立 preset 系統

## Phase 2：音樂與人聲

- 歌詞編輯優化
- 樂器比例設定
- 歌曲段落設定
- 重新生成某一段
- 人聲設定（女／男聲、台語／華語、音高、清晰度）

## Phase 3：AI 分鏡與 Storyboard

- 由歌詞自動分析畫面
- 自動生成 storyboard shots
- 5 秒 / 10 秒一格
- 產生 image prompt / video prompt

## Phase 4：圖片與影片

- Text-to-Image
- Image-to-Image
- Character Consistency
- 9:16 / 16:9
- 影片生成

## Phase 5：時間軸與輸出

- 伴奏軌
- 人聲軌
- 字幕軌
- 影片軌
- FFmpeg 輸出 MP4

## Phase 6：進階模式

- 一般 MV 模式
- 《貓掌江湖》模式
- 《喵台灣宇宙》模式
- 可擴展新增其他 canon profile

## 按照你目前需求的優先順序

1. 專案設定
2. 歌詞編輯
3. 音樂設定
4. 人聲設定
5. AI 分鏡
6. Storyboard
7. 圖片生成
8. 圖片轉影片
9. 字幕
10. Timeline
11. FFmpeg 合成
12. 輸出 MP4
