# 《貓掌江湖》模式說明

## Canon Rule

《貓掌江湖》是你未來最重要的長期模式，不能只當成一個圖層的風格，而要當成一個固定視覺規則集。

### 主要規則

- 所有角色皆為母喵
- 9:16 影片比例
- 電影級布袋戲風格
- 固定角色臉型
- 服裝固定
- 武器固定
- 不允許武器自動變形
- 角色色系固定
- 世界觀固定

## 內容建議

- Prompt 前綴：`cat wuxia puppet theater cinematic`
- Negative prompt：`weapon mutation, costume mismatch, inconsistent face`
- Reference image：可在後續補上固定角色圖
- Voice profile：固定女聲／英雄型聲線

## 運作方式

系統只要選擇 `maozhang-jianghu` preset，就會套用：

- 角色一致性
- 視覺規則
- Prompt template
- Negative prompt
- 音色與語言設定
- 影像比例與鏡頭規則
