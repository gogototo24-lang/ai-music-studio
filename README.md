# AI 音樂生成工作室

第一版原型，目標是建立一個可逐步擴充的 AI 音樂生成 Web App。

## v0.1 已有
- 歌曲名稱與歌詞輸入
- 曲風選擇
- 繁體中文／台語／混合語言
- 女聲聲線選擇
- 情緒與歌曲長度設定
- 產生標準化歌曲生成提示
- 匯出歌曲任務 JSON

## 下一階段
1. 串接真正的音樂生成 API
2. 加入台語 TTS／聲線模組
3. 儲存生成歷史
4. 下載 MP3
5. AI 歌詞助手
6. AI 封面圖生成
7. 手機版 PWA

## 本機使用
直接用瀏覽器開啟 `index.html` 即可。

> 注意：v0.1 是前端原型，不包含任何 API 金鑰。之後串接外部服務時，金鑰必須放在伺服器端，不要寫進前端程式碼。
